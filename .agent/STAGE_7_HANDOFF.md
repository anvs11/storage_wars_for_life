# Stage 7 · Приёмка игровой недели

Браузерный прогон на `79360a9`, Windows и Chrome 157.0.8103.79. На 360×640 использована эмуляция касаний, на 1280×900 — мышь, Tab и Enter. Проверка физического телефона остаётся на этапе выпуска.

Из корня прошли 129 тестов и сборка. Сервер разработки и предварительный просмотр запущены на 5173 и 4173 соответственно. Игровые действия выполнены через главную страницу собранной версии на 4173. На 5173 подготовлены контрольные профили.

    npm test
    npm run build
    npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
    npm run preview -- --host 127.0.0.1 --port 4173 --strictPort

## Чистый профиль до следующей недели

Для воспроизведения в изолированном профиле Playwright при создании новой игры использован seed профиля 64, подставленный в `crypto.getRandomValues` для одного `Uint32Array` длины 1. Все дальнейшие действия выполнены кнопками. Сохранение чистого профиля не подменялось.

1. Пройти пролог до ключей. Выставить электрический чайник за 2 000 ₽. Дома нажать «Подождать до дня», открыть отклики и принять предложение. Банк 2 000 ₽.
2. В гараже положить в коробку сначала настольную лампу, затем набор ключей. Дома дождаться вечера. До пятницы включительно завершать день двумя ожиданиями или оставшимся ожиданием, нажимать «Лечь спать» и «Проснуться». В пятницу день 5 довести до вечера, обновить страницу на экране ночи и проснуться в субботу.
3. Утром дня 6 выбрать барахолку и подтвердить поездку. Seed продажи 1434197262. Продалась лампа `home-lamp` за 555 ₽. Банк вырос с 2 000 до 2 555 ₽. В коробке остался `home-tools`. Квитанция пережила обновление. День 6, период «день», остался один выезд.
4. Вернуться домой, войти в обычный аукцион, спасовать и нажать «К выбору торгов». Банк 2 555 ₽. После возвращения наступил субботний вечер. Проснуться в воскресенье и перейти на понедельник, день 8, утро.
