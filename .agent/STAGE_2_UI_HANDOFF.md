# Stage 2 · Передача интерфейса от У2

Контракт и примеры У1 из `1b02122` включены в историю `stage-2/role-2`. Версия интерфейса — коммит, в котором появилась эта передача.

## Подключение

В `src/main.ts` импортировать `import { mountStage2 as mount } from './ui/mount';`. Вызов `mount(root, view, dispatch)` принимает `Stage2View` и `Stage2Dispatch` из `src/game/stage2-contract.ts`. Принятие команд, обновление состояния и повторный вызов `mount` остаются в точке входа У1. Экран отправляет `expectedRevision` из показанного представления. Для открытия передаёт `boxId`, для осмотра и продажи — `itemId`. Суммы в интерфейсе берутся из представления. Экспорт `mount` для Stage 1 работает через общую отрисовку гаража до подключения нового движка.

- `src/ui/mount.ts`, `src/ui/garage.css` — торги, инвентарь, квитанция, восстановление банка.
- `src/ui/story.ts`, `src/ui/story.css` — пролог. Четыре изображения в `src/ui/assets/`: `story-door.jpg`, `story-rain.jpg`, `story-driver.jpg`, `story-rental.jpg`.
- `src/ui/garage-scenes.ts` — изображения и описания по `sceneId`. Файлы `tutorial-garage.png`, `garage-workshop.jpg`, `garage-household.jpg` находятся в `src/ui/assets/`.
- `src/ui/stage2-preview.html` и `src/ui/stage2-preview.ts` — временный просмотр на примерах У1. У2 удалит его после успешного общего прогона.

Для просмотра на Windows запускал из корня `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`. Адрес `http://127.0.0.1:5174/src/ui/stage2-preview.html`. По умолчанию открывается пролог. Параметр `?view=recovery` открывает одноимённый пример сразу. Поддерживаются все ключи `stage2Views`. Параметры `?scene=workshop` и `?scene=household` меняют композицию при осмотре. Просмотр переключает подготовленные снимки. Следующий лот демонстрирует номер, фон и перенесённый банк, а его дальнейшие ставки используют учебные примеры.

## Результаты проверки

20 ноября 2026. Windows, Node.js 22.16.0, Chrome 157.0.8103.79. `npm run build` завершилась успешно, `npm test` прошла 7 из 7 тестов Stage 1. Корневая страница по-прежнему открывает Stage 1. Все 11 примеров Stage 2 загрузились на 360×640 с эмуляцией касания и на 1280×900 с мышью. Горизонтальной прокрутки не было, проверенные кнопки имели область не менее 44×44 px.

Через локальный просмотр пройдены шесть реплик, подтверждение или пропуск пролога, первая ставка с осмотром после ответа соперника, пас, открытие коробки, продажа поштучно и остатком, квитанция, следующий лот и переход от сортировки к торгам. Видимые суммы на контрольном маршруте совпали с примерами: банк $70, после продажи велосипеда $105, после открытия коробки по-прежнему $105, после продажи остатка $115 с выручкой $45 и прибылью $15. Закрытая карточка не показывала инструмент и его цену. Проверены отрицательная прибыль и недоступное повышение на дополнительных снимках. Через перехват вызова `dispatch` подтверждены ревизии всех 11 типов команд и ID для осмотра, открытия и продажи. Клавиатура прошла смену реплики, открытие, продажу и следующий лот с видимым фокусом.

Для общей приёмки нужен настоящий движок. На нём надо подтвердить начальный банк после обоих путей пролога, каталог и соперников, реальные выплаты и защиту от повторной продажи, сохранение и восстановление при обновлении страницы в разных фазах и доступ к заказу после цепочки убытков. Телефон в этом прогоне эмулировался.
