# Передача интерфейса Stage 3 от У2

Ветка `stage-3/role-2`, ревизия UI — коммит, добавивший этот отчёт. Контракт и примеры У1 включены с общей историей через `c2cdb26`.

## Подключение

В `src/main.ts` используй именованный импорт и передай подтверждённое представление с обработчиком команд.

```ts
import { mountStage3 } from './ui/mount';

mountStage3(root, view, dispatch);
```

- `src/ui/hub.ts` отображает банк, рейтинг, пороги, классы торгов, досуг, улучшения и звонок в аэропорт.
- `src/ui/baggage.ts` ведёт от предложения аэропорта до квитанции, `src/ui/inventory.ts` содержит общую разметку находок, открытий и продаж. Пролог и гараж используют общие обработчики отрисовки Stage 2 и Stage 3.
- Фоны `src/ui/assets/garage-selected.jpg` и `src/ui/assets/garage-antiques.jpg` подключены через `garage-scenes.ts` по идентификаторам `selected` и `antiques`. Остальные сцены используют прежние ресурсы.
- Главная страница пока вызывает `mountStage2`. После проверки общей сборки убрать временный просмотр, макет и переходный экспорт, когда исчезнет его последний вызов.

## Локальный просмотр

```sh
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Временная страница — [просмотр Stage 3](http://127.0.0.1:5173/src/ui/stage3-preview.html?example=hubStart). Параметр `example` принимает любой ключ из списка примеров. Перед покупкой чемодана можно выбрать дешёвый или дорогой исход. Дополнительные снимки связывают пролог, торги, сортировку и квитанции. Действия переключают заранее записанные представления. Например, расходы из начального хаба переводят к одному из контрольных порогов рейтинга, а инвентарь дорогих гаражей ведёт к продаже остатка. Для прохождения произвольных сочетаний действий подключи движок.

## Результаты

Проверено через Playwright в Chrome 157.0.8103.79 на Windows 11, сборка ОС 26200. На 360×640 использована эмуляция касаний, на 1280×900 — мышь и Tab, Enter, Space. На каждом размере открыты по URL все 16 примеров У1 и 43 дополнительных снимка. Изображения загрузились. Измеренные размеры кнопок и полей выбора не меньше 44×44 px. Горизонтальной прокрутки не было, включая отдельную проверку с длинным названием карточки.

| Сценарий | Что показал интерфейс |
|---|---|
| Рейтинг и доступ | Проверены 0/7/8/17/18, ближайший порог и сообщение обо всех открытых классах. «Нужно 8 очков» отличается от «Нужно $50 для ставки». Из банка $19 обычные торги ведут к сортировке, пример после неё показывает $20. |
| Досуг и улучшения | Закусочная предлагает $5 за +1 или $7 за +2. Проверены покупка, нехватка средств и отметки о купленных доме и машине. |
| Обычные торги | Ставка $20, ответ $25, осмотр велосипеда в торгах, покупка за $30, продажа велосипеда до банка $105, открытие коробки и продажа остатка. Квитанция +$15, переход к выбору торгов с $115. |
| Дорогие торги | Старт $50 и $90, пас и возврат, осмотр на стадии торгов, вскрытие коробок, в антикварном лоте оба порядка. Квитанции снимков +$12 и −$21. |
| Аэропорт | Отказ до оплаты сохраняет $100. При банке $19 покупки нет. После оплаты $25 банк $75, на карточке закрытого чемодана нет находки или её цены. Продажа за $4 даёт −$21 и банк $79, продажа за $60 даёт +$35 и банк $135. |
| Команды и фокус | Проверены отправленные ревизии и идентификаторы при выборе класса, трате, осмотре, открытии и продаже. Клавиатурный фокус виден при входе в лот, после появления подсказки, на экранах аэропорта, после вскрытия, продажи и возврата. |

`npm test` — 17 из 17. `npm run build` — успешно. В браузере на главной странице Stage 2 проверен переход из пролога к первой ставке.
