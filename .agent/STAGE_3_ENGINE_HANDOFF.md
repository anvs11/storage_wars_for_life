# Stage 3 · Передача правил У2

21 ноября 2026. Источник для сборки — ветка `stage-3/role-1`, общий контракт `c2cdb26`. Интерфейс У2 — `cb020f0`. На ветке У1 главная страница запускает Stage 2. Для подключения импортировать `newGame` и `getView` из `src/game/stage3-engine.ts`, `load`, `save` и `applySavedCommand` из `src/platform/stage3-save.ts`. Снимки v2 остаются в тех же ключах браузерного хранилища. Чтение v1 переносит исходный лот и его шаг ставок, банк, статус, прогресс пролога, осмотр, активных соперников, открытые коробки, продажи и квитанцию. Новый снимок записывается при сохранении, в том числе после первой принятой команды.

## Как воспроизвести

Из корня проекта на Node.js 22.12+ выполнить:

    npm test
    npm run build
    npm test -- src/game/stage3-balance.test.ts --reporter=verbose --silent=false
    npm test -- src/game/stage3-routes.test.ts src/game/stage3-engine.test.ts src/platform/stage3-save.test.ts

`newGame(seed)` принимает фиксированный seed в тестах. Сценарии ниже используют настоящие команды с текущей ревизией. В браузерной игре источник случайности создаётся при новом профиле, в публичный интерфейс seed не передаётся.

Соперник отвечает $30 → $40 → $50. Следующая ставка в обоих случаях $60. До вскрытия экраны совпадают.

## Багаж

На свежем профиле пропустите пролог, спасуйте в учебном гараже и перейдите к выбору торгов с $100. Позвоните, подтвердите $25, перезагрузите, откройте чемодан, снова перезагрузите и продайте находку. При оплате остаётся $75, вскрытие денег не начисляет. Тесты также симулируют отказ записи перед первой оплатой и проверяют, что повтор выбирает то же содержимое.

| Seed профиля | Продажа | Результат | Банк |
| ---: | ---: | ---: | ---: |
| 0 | $4 | −$21 | $79 |
| 2 | $25 | $0 | $100 |
| 1 | $60 | +$35 | $135 |

Пороги выпадения 0,45 и 0,80 соответствуют весам 45/35/20. Багаж меняет банк. Статус за продажу багажа не начисляется.

## Баланс двух стратегий

По 1 000 лотов на класс в каждой выборке. Начальные seed: обучение `2654435769` (`0x9e3779b9`), основная `828039445` (`0x315ae115`), отложенная `1914466619` (`0x721c713b`). Для класса seed смешивается через XOR с его индексом, умноженным на `0x85ebca6b`. Точные последовательности воспроизводит `stage3-balance.test.ts`. Банк $10 000 исключает отсев из-за денег. Обе стратегии используют одни и те же лоты и ставки соперников. При сравнении пас даёт нулевой итог на предложенный лот.

Одна стратегия повышает до победы. Другая заранее складывает середины видимых диапазонов с медианной оценкой коробок из обучения и оставляет 15% резерва. На подбор отводится до 28 попыток с допуском 6% или $2, затем берётся ближайший допустимый набор. Предметы выбираются по редкости, состояние равномерно из трёх вариантов, цена равномерно внутри целочисленного диапазона состояния. Выбывший соперник пропускает оставшиеся раунды. Шаг для игрока и соперников составляет $5 до текущей цены $50, $10 от $50 и $15 от $100. Учебный и открытые лоты Stage 2 сохраняют исходный шаг.

На первой основной выборке обычных лотов стратегия с пределом принесла $9,428 на предложение при $9,846 у стратегии до победы. Увеличение верхнего множителя обычных соперников с 1,19 до 1,28 дало положительную разницу на обеих выборках. Для отборных верхнюю границу подняли с 1,28 до 1,34 после разницы в $0,025 на предложение на основной выборке. Итоговые параметры проходят целевые критерии на всех шести выборках.
