# Учебный гараж · передача от У2 к У1

## Композиция

Сцена снята с порога. Поднятая металлическая дверь видна полосой в верхней части кадра, направляющие обрамляют проём. Слева на переднем плане стоит велосипед. Свет с улицы падает на потёртую нижнюю трубу рамы. Справа, чуть глубже, стоит заклеенная коробка. Видны обе находки и свободный пол между ними. Кнопка «Осмотреть велосипед» привязана к раме и доступна касанием, мышью и клавиатурой. На коробке достаточно подписи «Закрытая коробка». Подсказка открывается под сценой.

При ширине 360 px и боковых полях по 12 px сцена занимает 336 px. В шапке «Гараж» слева и «Банк $100» справа. Ниже проём, велосипед слева и коробка справа. Под проёмом строка осмотра. Внизу видны статус торгов и две кнопки высотой от 44 px. Если экран низкий, область сцены и подсказки прокручивается, а панель действий остаётся у нижнего края. Последняя строка содержимого не перекрывается панелью.

При ширине 1280 px и полях по 32 px проём занимает около 872 px слева, справа панель действий шириной 320 px, между ними 24 px. Шапка с банком общая. Подсказка под проёмом, статус и кнопки в правой панели. После завершения сделки место статуса занимает квитанция.

## Подписи и ход торгов

До касания под сценой «Осмотрите вещи у входа». После касания «Рама потёрта. Если колёса ровные, за велосипед можно выручить $25–40». Диапазон предварительный и относится к одному предмету. На торгах сохраняется доступ к подсказке. Текст для коробки «Содержимое видно после покупки».

| Момент | Что видит игрок | Действия |
|---|---|---|
| Осмотр | «Старт $20», «Банк $100» | «Ставка $20», «Пас», осмотр |
| Первая ставка | «Ваша ставка $20». Эта строка остаётся видимой рядом с ответом соперника, даже если правила сразу возвращают его ответ. | Один клик отправляет одну команду `bid`. |
| Ответ соперника | «Соперник: $25», «Банк $100» | «Ставка $30», «Пас», осмотр |
| Победа | «Гараж куплен за $30», «Банк $70», «Велосипед $35», «Инструмент из коробки $10» | «Продать всё» |
| Пас | «Вы вышли из торгов», «Списано $0», «Банк $100» | «Следующий гараж» |
| Квитанция | «Покупка $30», «Выручка $45», «Прибыль +$15», «Банк $115» | «Следующий гараж» |

## Минимум данных GameView для У1

Имена полей условные. У1 определяет точные типы. На текущем экране UI использует `revision` из представления как `expectedRevision` команды. Для `inspect` также передаёт id предмета.

- Фаза `inspection | bidding | reveal | result`, ревизия и банк.
- Видимые предметы с устойчивым id, названием и подсказкой после осмотра. Для велосипеда нужны наблюдение и видимый диапазон перепродажи. Для коробки достаточно имени до выигрыша.
- Разрешённые команды `inspect`, `bid`, `pass`, `sellAll`, `nextLot`. Допустимость осмотра можно указывать для каждого предмета.
- Сумма следующей ставки, текущая ведущая ставка с владельцем и последняя ставка игрока. Для ответа соперника одна модель представления должна позволять вывести «Ваша ставка $20» и «Соперник: $25». Отдельный таймер для учебного лота не требуется.
- После покупки показать сумму покупки и раскрытые находки с названиями и ценами продажи. Для `result` передать исход `passed` или `sold`. Для продажи нужны цена покупки, выручка и прибыль, для паса достаточно исхода и банка.

Для примеров от У1 нужны осмотр со стартом $20, ответ соперника $25 при следующей ставке $30, раскрытие с банком $70 и два исхода с банком $100 или $115. У2 использует эти примеры при подключении интерфейса.

## Передача готового экрана

Основа проверки — `b4c1372`, контракт `stage-1-contract-v1`. В `src/main.ts` импортировать `import { mount } from './ui/mount';` и вызывать `mount(root, getView(state), dispatch)` при первом показе и после принятых команд. `mount` заменяет содержимое переданного контейнера и восстанавливает фокус внутри экрана, если действие началось с элемента в контейнере. Команда содержит ревизию показанного представления и, для осмотра, ID предмета. Сумму ставки определяет движок.

- `src/ui/mount.ts` содержит отрисовку и обработчики.
- `src/ui/garage.css` подключается из `mount.ts`.
- `src/ui/assets/tutorial-garage.png` — оригинальная иллюстрация поднятой двери, велосипеда и коробки. Она импортируется через Vite.
- `src/ui/preview.html` и `src/ui/preview.ts` — временная страница с согласованными примерами. После подключения движка в `src/main.ts` удалить оба файла.

Из корня запустить `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`. Открыть `http://127.0.0.1:5173/src/ui/preview.html`. Параметр `?long-labels` удлиняет названия предметов для проверки переноса строк.

### Результаты просмотра

- Chrome 157.0.8103.79, 1280×900, мышь. Осмотр показал оценку $25–40, первая ставка показала $20 игрока и $25 соперника. После ставки $30 банк $70, обе находки видны. Продажа дала выручку $45, прибыль $15 и банк $115. Проверены команды с ревизиями 0–4, отклонение повторной продажи в просмотре и переход к следующему лоту.
- Тот же Chrome, 360×640, эмуляция касания. С длинными названиями ширина содержимого совпала с шириной окна. Все проверенные кнопки имели область не меньше 44×44 px. Осмотр, ставка $20, пас и переход к следующему гаражу с банком $100 сработали касанием. На этой же ширине клавиши Tab, Enter и Space прошли осмотр, обе ставки и продажу до банка $115.
- `npm run build` прошла на Node.js 22.16.0. `npm test` вернула код 1 с сообщением `No test files found`. Сценарии пройдены на временной странице с примерами. Проверка с настоящим движком и на физическом телефоне остаётся на интеграцию.
